# 🚗 Car Services

A responsive landing page for a car maintenance and repair business, built with HTML, CSS, and Bootstrap 5.

![Car Services Preview](https://i.imgur.com/vsmN0TB.png)

## 🔗 Links

- **Live Demo:** [car-servicez.netlify.app](https://car-servicez.netlify.app/)
- **Repository:** [github.com/muh-musa/Car-Services](https://github.com/muh-musa/Car-Services)

## 📋 Overview

Car Services is a single-page website for a car maintenance business, featuring:

- A hero section with clear calls to action
- A services showcase (car service, auto service, maintenance, support)
- A gallery of completed work
- A "Why choose us" section highlighting the team's strengths
- A customer testimonials carousel
- A blog preview section
- A newsletter sign-up and a full contact/footer section

The site is fully responsive and works across mobile, tablet, and desktop screens.

## 🛠️ Built With

- **Semantic HTML5** markup
- **CSS3** with custom properties
- **Bootstrap 5.1** for layout, components, and responsiveness
- **Font Awesome** for icons
- Mobile-first, flexbox/grid-based layout

## 🚀 Getting Started

Clone the repository and open `index.html` directly in your browser — no build step required:

```bash
git clone https://github.com/muh-musa/Car-Services.git
cd Car-Services/Car-Services
open index.html   # or just double-click the file
```

## 🎯 What I Learned

This project was a deep dive into Bootstrap 5.1 — building a navbar, hero section, card layouts, a testimonial carousel, and a footer, and connecting them into a smooth single-page navigation experience with anchor links.
